3. РЕЄСТР ЗДАВАЛЬНИХ АРТЕФАКТІВ

1. 01_Input_Pack_v0.1.md
   - Повний аналітичний відбір вимог із вихідної специфікації SD_Spec.docx.
   - Покриває всі 8 US, рівно 33 змістовні AC, UI-релевантні BR, виключення та Q-ID.
2. 02_Screen_Map_v0.1.md
   - Архітектура інтерфейсу: 3 продуктових екрани, 1 модалка, 3 стани списку, 9 фреймів.
   - Повна матриця переходів T-01..T-20 та текстові User Flows.
3. 03_Screen_Contracts.md (v1.0 APPROVED)
   - Формальні контракти поверхонь для розробника (C-ID, Visible data, States).
   - Матриця ролей (Permission Matrix) із закріпленням права Assignee Only для статусу.
   - Матриця переходів статусів (BR-08.1), предикат Important та повна таблиця Traceability (33 AC).
   - Тестові сценарії TC-01..TC-16 із межами доказовості.
4. 04_Plan_Review.md
   - Критична рецензія плану до початку макетування.
   - Виявлення та фіксація дефектів DEF-01 (AC-07.4) та DEF-02 (дедлок призначення).
   - Схвалення переходу до фази Figma (Контроль B: PLAN READY).
5. 05_Figma_Brief_v1.0.md
   - Компактний самодостатній англомовний бриф для генератора Figma Agent.
   - Жорсткі обмеження, структура шарів, тестові дані та acceptance checklist.
6. 06_Review_Report_and_Defects.md
   - Фінальний звіт аудиту відповідності макета вимогам (Контроль D).
   - Таблиця доказів PASS/FAIL, Usability спостереження та закритий Defect/Change Log.
7. 07_Prototype_Test_Record.md
   - Протокол ручного проходження сценаріїв у режимі Figma Present (T-01..T-10).
   - Мінітест зі стороннім користувачем та чітке розмежування симуляції від бекенду.
8. AI_Interaction_Log.md
   - Детальний журнал усіх звернень до моделей штучного інтелекту (ChatGPT Free, Figma Agent).
   - Фіксація промптів, відповідей, лімітів та підтвердження відтворюваності.
9. BEFORE_REVIEW.fig
